Mandatos: prep lesson video

A prep lesson on commands (mandatos) recorded for the correspondence course. Captions run throughout, and an overlay added in YuJa corrects an error in the recording without re-recording the lesson. In Canvas, the same video runs as a YuJa video quiz, with questions that appear at set points as learners watch.

Five H5P interactive videos from Module 1 of the correspondence course, including Un día para el profesor and Pronombres reflexivos, indirectos, directos. Each pauses at set points for ungraded practice activities, and each carries captions.
